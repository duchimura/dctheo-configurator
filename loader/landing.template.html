D_C_Theo Edition — GP2040-CE UI Loader

This tool loads the D_C_Theo web interface into the page your GP2040-CE controller already serves at http://192.168.7.1 — no reflashing, no install, nothing to download. It works with stock GP2040-CE firmware.

First, make sure your browser's bookmarks bar is visible, then drag this link onto it:

D_C_Theo UI

To use it: put your controller into web-config mode, open http://192.168.7.1 in your browser, then click the bookmarklet.

If your browser won't let you drag the link above, create a new bookmark by hand and paste this into its URL field: 

__BOOKMARKLET_CODE__
This does not flash or modify your controller's firmware, and it doesn't store anything anywhere — it only changes what your browser shows, for as long as that tab stays open. Any changes you save (button mappings, profiles, and so on) are written to the controller you're connected to, exactly as the stock interface does.
